# 模块指南

| 模块                   | 职责                                        |
| ---------------------- | ------------------------------------------- |
| `collection-cache.mjs` | 存储每种收藏状态的完整候选数据和评分缓存。  |
| `bangumi-client.mjs`   | 发起列表与条目请求，解析 HTTP 响应及 HTML。 |
| `page-scheduler.mjs`   | 管理页面内共享的列表请求名额和前台优先级。  |
| `draw-engine.mjs`      | 随机选取候选条目，获取评分并构造卡片数据。  |
| `gacha-session.mjs`    | 组织收藏获取、抽卡生命周期及用户命令。      |
| `gacha-view.mjs`       | 呈现 DOM、样式、进度、结果及用户操作。      |
| `browser-adapter.mjs`  | 提供浏览器环境适配。                        |
| `shared.mjs`           | 提供跨模块使用的收藏状态及条目工具。        |
| `main.mjs`             | 解析路由，组装并启动会话；保持轻量。        |

测试通过模块接口注入外部请求、存储、时钟和随机数。行为规则见 [规格说明](spec.md)，构建与验证见 [开发与交付](development.md)。
